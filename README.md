# TTierList

Локальное приложение для тир-листов в стиле [TierMaker](https://tiermaker.com/): загружаешь картинки, заполняешь карточки и раскладываешь их по тирам перетаскиванием.

Стек: Java 21, Spring Boot, Thymeleaf, H2 (файловая база).

## Запуск

Нужна только установленная Java 21.

```powershell
.\gradlew.bat bootRun
```

Затем открыть http://localhost:8081/cards

Одновременно может работать только один экземпляр приложения: H2 блокирует файл базы.

## Страницы

- `/cards` — просмотр: попапы при наведении, поиск по имени, фильтр по тегам.
- `/cards/info` — раскладка карточек по тирам перетаскиванием.
- `/cards/{id}` — страница карточки.
- `/cards/new` — создание карточки и загрузка картинок пачкой.
- `/cards/bulk-edit-tags` — массовое редактирование тегов.
- `/tags` — управление тегами.

## Данные

- База: `db/data.mv.db`
- Картинки: `src/main/resources/static/css/uploads/`

Обе папки не хранятся в git — это единственная копия данных, делайте бэкап сами.
