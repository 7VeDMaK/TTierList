## How to Run the Application

1. **Build and Run the Container**  
   Execute the following command in your terminal:
   ```sh
   docker compose up```

2. **Launch the Application**  
   After the container is running, start the application by running the ADListApplication.java file.


3. **Test the Application**  
The application is currently accessible at: http://localhost:8081/hello?name=bro


4. **Database connection**  
   ```User: user  
   Password: password  
   Port: 5431  
   URL: jdbc:postgresql://localhost:5431/adlist-db```
   
5. **Now you can build this project and use .jar to give other people your app with current db**
